# CarMaker-SUMO-Co-Simulation-HIL-Office-CM-14.1.1-
A co-simulation library for IPG CarMaker to work with SUMO for handling the surrounding traffic. Works with both the HIL and Office versions. Multi-rate, bi-directional. Includes a ego-state prediction algorithm to run SUMO one time horizon in advance. Supports non-ego CM controlled vehicles, too.
